# Proposed next step, not implemented or proved

The observed inference blocker is the unmodeled `core::slice::iter_mut` call. Adding it to an external-call allowlist would not establish mutable state effects, early-break behavior or the returned borrow, and is not an acceptable fix. Static source inspection also shows that current slice inference describes immutable views (`source/vir/src/infer/slices.rs`) and that ordinary scalar signature eligibility excludes mutable buffers and slice returns (`eligibility.rs`). These are design constraints, not downstream experimental failures.

The smallest useful bounded extension suggested by the checked partial proof is **ordinary goal assistance for unsigned shift-until-zero iterator loops**. It would remove the known mechanical length/safety annotations first. It would not certify the full canonical property or introduce an inferred encoder summary.

Recognize only a structurally validated loop over the canonical mutable iterator of a fixed scalar array: an unsigned scalar initialized from an immutable input, zero counter, constant positive right shift, early break exactly when the shifted scalar is zero, and unit counter increment on the continuing path. Bound widths to Rust unsigned machine types and array lengths to the existing finite array budget. Match resolved standard-library identity, types and contracts; reject custom iterators, aliases, hidden callbacks, extra state changes or nonmatching control flow. Byte payload writes remain original ordinary obligations, not trusted summaries.

Generate candidate invariants relating the scalar to the original input shifted by `step * index`, the counter to the iterator ghost index, and the fixed iterator length. Derive the maximum continuing index from `ceil(bit_width/step)`, require sufficient array capacity as a recognition condition on its static type, and emit the initial/step/final shift theorems as checked bit-vector queries. Install proof annotations only, preserving every executable statement, parameter domain and authored goal. If a candidate fails, no theorem, assumption or interface may escape. Resource/unsupported failures must remain distinct from false postconditions.

Acceptance would require generic positive widths/steps and capacities, arbitrary initial buffers, zero and maximum inputs, and semantic/safety negatives for wrong shifts, counter updates, capacities, breaks and returned ranges. Check actual auxiliary theorem failures independently of ordinary caller failures; retain source comparison and full-crate checking. Test cold/warm caches, poisoned metadata, all three independent inference precision checks on unaffected inferred functions, and seeded publication rejection. Before claiming transfer, freeze and prove a second unrelated pinned upstream loop, rather than another unsigned-varint wrapper. No such second application was selected or proved in this experiment.

This proposal is deliberately limited to the mechanical work actually isolated. The full canonical goal still needs a checked written-prefix/radix invariant and mutable-reference observation laws connecting final iterator referents to the returned slice. That semantic relation has not been authored successfully, so there is no demonstrated single bounded engine extension sufficient to remove all work for the required property. Do not classify the current result as mechanical-annotation removal, canonical end-to-end transfer, or stateful authored-invariant acceptance.

For direct inference, the concrete prerequisite is a bounded mutable-array effect relation, not an assumed `iter_mut` result. Represent the initial array, current array, iterator position and optional stopped position as symbolic state; lower only resolved canonical `IterMut` over that fixed array, with updates confined to the currently yielded scalar referent. A returned prefix must carry its checked bounds and relation to the final array, preserving Rust borrow checking. Generate a finite candidate state relation, and check its soundness, maximal safe domain and exactness against the untouched source. Cache only typed candidate formulas, never proofs or trusted application summaries. This requires coordinated signature, loop-state, return-view and metadata work in addition to the ordinary mechanical assistance; it is not a justified one-line bridge or a demonstrated bounded solution here. Wrong referent/index, early break, continuation-bit and stale-export controls would have to fail independently before this could be used for canonical inference.
