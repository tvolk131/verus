# Static arithmetic and trust audit

Reviewed new shipping `checked_foreign_packing.rs` against accepted35bc7b12/d27f4dd9. Only production delta is this file; new compiler test is local_checked_packing.rs. Existing checked_foreign.rs, commands/context/Query/export and global versions are unchanged.

For W in {8,16,32,64}, all theorem variables are locally bound U(W); explicit 0 <= x < 2^n premises are included. k=0 emits exactly left/right shift identity, not a degenerate split law. For 0<k<W the OR-as-addition and high-mask positivity laws restrict low<2^k and high<2^(W-k), so shifting loses no high bits and mathematical multiplication/addition is exact. The single-bit positivity law restricts high<2. Low projection permits high's entire W-bit unsigned domain because truncation of high cannot affect low k bits.

A contiguous [lo,hi) mask gives an extraction less than 2^(hi-lo), with 0<=lo<hi<=W; hi=W is a valid mask endpoint, never a W-bit shift. Three-field laws use 0<lo<hi<W; low<2^lo, middle<2^(hi-lo), and upper<2^W. The upper field is deliberately unrestricted within its full unsigned type: discarded upper bits do not affect either lower projection. These are integer/BV identities, not Item/Permission laws or native permissions.

The existing BV translator minimally sizes literal integers (2^W is W+1 bits, not zero), losslessly widens Add/Mul, zero-extends comparisons, quantifies finite-width binders in local scope, and clips left shift to its explicit width. Right shift is logical for these unsigned expressions. The ordinary integer translation and BV translation retain the same explicit ranges and finite left-shift operators. BV drops trigger annotations; ordinary quantifiers use a packed/extracted expression containing all quantified variables. Names are AirLocal bound variables, never application references; each quantifier scopes repeated binder names independently.

`constant` recurses at most64 nodes through literal/empty-block/finite bitwise trees, computes with BigInt and masks to W bits, and rejects shifts >=W. Proposed equality checks the reconstructed expression itself; it never assumes a guessed constant call. Shift RHS is represented as U64 for conversion. Discovery's `number`/`mask_number` peeling may overrecognize clips or literal-return functions, but those values only select generic closed theorems: they are not used to assert caller facts. Unsupported opaque/nested-call/signed/mask/reversed shapes can omit help conservatively. Constant reconstruction rejects unsupported Clip/other AST nodes instead of guessing semantics.

Discovery visits up to4096 statement/expression nodes, including direct returns, assignments, assertions/assumptions and if branches, but not arbitrary call arguments, tuples, loops or isolated proof/closure scopes. Constants are sorted and the first32 local constants are considered (not the first32 successful folds). At most8 sorted width/shift shapes and16 mask fields survive. A valid body can fail through omission or through an auxiliary timeout; neither may be reported as success. mask_field's finite search has at most2080 comparisons at W64; it supplies shape hints only.

Conservative maximum facts/body =32 +8*6 +3*C(8,2) +16 =180. k0 emits2 instead of6, mixed widths omit pairs, and a normally discovered width contributes zero before truncation, so observed counts are smaller. No deduplication occurs between constant-derived mask fields and shape-derived fields or across bodies; some facts are unnecessary for a particular body. Verification count measures checked solver cost, not strengthened contracts/native coverage.

Each exact proposed Arc is cloned into AssertBitVector(empty requires, [fact]) and moved into Assume(fact). The original body remains the last statement. Existing SST-to-AIR emits separate ordinary required BV queries; caller assumptions and preceding packing assumptions do not enter those queries. Failed/unknown auxiliaries must fail overall verification even when main-body assumptions suffice. No summary/proof-result cache, model axiom, frontend skip or inferred precision query is added. Existing bool capability and all-domain Eq inference remain separate freshly checked obligations; local export embargo remains in force.

The normal verifier's unchanged ValidityResult handling was checked explicitly: Canceled marks unproved and increments error count; Invalid with missing model/error (including BV unknown-style failure) also marks unproved and increments errors; UnexpectedOutput/type errors abort. The auxiliary CommandsWithContext is required/error level. No timeout/unknown was manufactured; false-constant source control supplies the fresh executable failure-propagation check.
