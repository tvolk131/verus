# Procedure limits and exclusions

This review reads only its own checkout/exact ancestor instructions, immutable Git commits and the explicitly named completed artifact roots. It performs no subdelegation, push/PR, network/install, process-table inspection, live parent/sibling checkout/build/cache/config access, WORK_STATE access, certificate edits or production fixes. All new tracked files are under evidence/item-packing-review/. Applications and ordinary semantic controls run with full verification, --no-cheating and --compile. Inherited export/incomplete guard regressions deliberately request rejection and are not successful application proofs.

The default sandbox failed at startup (`bwrap: loopback: Failed RTM_NEWADDR: Operation not permitted`); subsequent commands used approved escalation. No automatic approval rejection occurred.
