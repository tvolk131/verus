# Redb critical path108 — native storage correspondence is the priority

Both independent source assessments are retained unchanged. They agree that no
inspected final cell is one helper lemma or Arc diagnostic away from closure.
The strongest existing evidence is conditional selection/recovery, not an
established nearest complete native theorem. No percentage or ETA is justified.

The [first-cell assessment](FIRST-CELL-REPORT.md) recommends **two-phase
acknowledged durability** as a working target, not a proved cheapest route.
Its milestone keeps the original operations, supported sizes, required errors,
both crash kinds, interrupted recovery and finite two-phase Immediate histories.
No fixed-geometry slice or caller validity premise can silently replace that cell.

The [protocol assessment](PROTOCOL-REPORT.md) identifies the concrete missing
edge: actual buffered native `write_header`/`flush` must establish the storage
events consumed by the existing checked recovery bridges. Coalesced full-header
writes, stale-secondary crash prefixes and errors after successful sync require
explicit treatment. Field mutation, slot selection and an assumed disk trace
are not proofs of native publication or public acknowledgement.

An immutable Arc view is not a prerequisite to every protocol lemma. The Arc
diagnostic remains separately unapproved and would not establish native cache/
backend effects. It should not serialize all protocol work. Complete native
cells still need legitimate resource/storage interfaces and source/runtime/trust
bindings; neither assessment found an already established interface for closure.

`FIRST-CELL-HANDOFF.tar.gz` and `PROTOCOL-HANDOFF.tar.gz` retain all report/input/
accounting payloads byte-exact. [RESULTS.json](RESULTS.json) records archive hashes,
33- and 36-input rechecks, limitations and unchanged source-only accounting.
No implementation, build, verification, primitive adoption or new proof credit
was authorized by these assessments. All eighteen final cells remain **OPEN**.

The recommended next decision is one bounded native commit-to-storage refinement
candidate and independent review, including the checked cache/backend binding
work it actually needs. That authorization must not silently adopt new laws,
assume away native premises, weaken S0 or claim a complete cell from a local slice.
