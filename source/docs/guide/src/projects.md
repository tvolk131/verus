# Project Setup and Development

This chapter offers advice on verifying and building your project with [`cargo
verus`](./cargo_verus.md), [documenting your verified code](./verusdoc.md) with
Rustdoc, and dealing with [potential compile errors](./erasure.md) when
compiling Verus-verified code with normal Rust tools.

For the experimental inference prototype, see
[adopting Verus Infer in an existing codebase](infer_adoption.md). It covers
choosing application goals, inferring helper contracts, supplying private-data
views, and using explicit contracts or proofs where automation needs support.
