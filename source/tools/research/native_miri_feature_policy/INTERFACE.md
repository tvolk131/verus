# Pinned Miri feature-policy inspection

Read and authenticate only two first-party source files at the compiler commit
already used by native extraction. The package manifest's default feature list
and the compiler FxHashSet re-export inform the active lookup proof's scope.
This does not run a Miri build, observe its actual command-line feature overrides,
prove cache correctness, or prove the underlying hash/set semantics.

HTTP acquisition preceded this checker epoch. Source bytes, Git blob IDs and
HTTP receipt hashes are retained privately; pins and checker are frozen before
the local inspector runs. No downloaded source is executed or installed.
An uncached helper proof is not a proof of the package-default cached path.
Neither a feature list nor a re-export supplies an assumed native contract.

All application domains and checks remain required: canonical inherited6/0,
full HMAC inherited1/1 unproved, native0,44+3/101 obligations open,
publication=false, goal_complete=false. Source inspection is not native proof.
