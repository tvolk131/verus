# Frozen replay

From this checkout, use the already installed, pinned Rocq toolchain and named
completed dependency artifacts. No installation or shared build is performed.

```sh
python3 -B source/tools/research/model_caller_writer/check.py \
  --freeze source/tools/research/model_caller_writer/final-freeze.json \
  --output /tmp/model-caller-writer-replay-001
```

The output path must be fresh and outside the repository. The checker first
requires both authenticated `baseline-ready.json` and its successful durable
receipt, the immutable 115a618d foundation (523 sources / 284 objects), exact
compiler/checker/runner/opam bindings, and GMP manifest
`332763a92d52a35f1623c7383970e6cd290b5010c426ca5bb15b21efc7f0bb37`.
It authenticates dependency receipts against committed pins and checks every
selected dependency source/object. The selected namespace loadpaths and pinned
Coq/OCaml/GMP runtime inputs are frozen and guarded through success.

Each trial freezes its sources, interface, checker/support files, dependencies,
and complete external inventory before compiling. Normal `coqc -q` compiles
all three modules into a private directory. Separate normally compiled modules
print assumptions and proof terms for every declaration, including their own
inventory helpers. All constructors, instances and obligations are accounted
for: none are generated by these candidate sources (the checker rejects such
constructs). Full recursive `coqchk -o` checks all three modules and both
inventory modules, without admission, exclusion or unsafe flags. It checks the
exact kernel declaration inventory, permitted inherited logical principles,
and all retained inputs and private products before recording success.

The only inherited logical principles permitted are dependent functional
extensionality and `Eq_rect_eq`, already present in the pinned dependencies.
No new axiom, primitive, trusted summary or application-specific premise is
introduced. The MODEL typing/aliveness/credit premises and remaining native
work are described in `INTERFACE.md` and `REPORT.md`.

`STATUS.json` binds the final private receipt, source and object hashes, freeze,
and toolchain. `TRUST_INVENTORY.json` records assumptions for all declarations
and generated inventory helpers. Private logs and objects are not committed.
Earlier proof-development failures establish no semantic negative result.
