# Candidate protocol signatures, before proof trials

Generic `shorter_no_write` takes an existing unique model context element and
ordinary local/external lifetime contexts. It executes `Newlft;; ReBor;; Endlft;;
Skip`, preserves the arbitrary frame (including any ancestor restoration) and
recovers an original-lifetime unique context at the same path. Its observation
relates recovered current to original current and recovered future to original
future. No input final/current equality or client lifetime token is supplied.

The generic WP lifetime-end helper is a continuation form of `type_endlft`,
retaining the existing resolution and blocked-context rules and operational
three-Skip `Endlft`. `ReBor` is two Skip expressions. Time and later credits
are generated by the existing operational time rules, not new premises.

Next candidate signatures will instantiate initialized bytes with arbitrary
interior heap/frame at generic lengths and 10/128, resolve only the recovered
parent with the original rule, and refute a blanket unchanged law for writes.
Each changed script is frozen and retained before compilation by `develop.py`.
All native 0/44/3/101 limits and full HMAC 1/1 remain; publication=false.
