REDB retains arbitrary valid multiword/padded trees, ragged/zero lengths and all configured actual orders. Its invariant and legal-free premise are explicit: the released interval must be in range and disjoint from represented free pages. True bits can represent split blocks, so a true bit alone is not a legal-free premise. Page conservation concerns semantic free pages and their complement, not an ownership ledger or the executable weighted count_free_pages loop. That loop, construction/resize/search, native crate integration, crash consistency and whole-database correctness remain unproved.

Fedimint retains all four original Keychain fields and genuine crypto types. Its initializer domain is every arbitrary signature/index with index below the actual reported configuration length; an empty configuration has no safe index, and the original out-of-bounds panic boundary remains. Associated types are resolved to their actual64-byte/NodeMap types and the method is projected into an inherent impl. Full external-trait/native crate integration is not proved. Three stock opaque nominal TYPE declarations supply identity only, with no crypto, representation, clone or method law.

F3-C proves configuration-linked initialization, not that missing quorum-admission correspondence.
