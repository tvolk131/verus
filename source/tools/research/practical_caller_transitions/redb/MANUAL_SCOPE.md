The full interval/invariant baseline (corrected.rs) reaches original bodies but exceeds default solver resources with unproved validity, success condition, page set effect, rejection identity and recursive free legality obligations. It is RESOURCE_FAILURE with useful diagnostic locations, not a clean semantic negative. Keep it in the denominator. No new foundations are needed merely to parse the body.

manual.rs attempts the preregistered partial guarantee on those SAME original callers: exact logical bit-vector transition trace, full physical rejection identity, original bounds/debug safety, layout and nested storage frames, returned merge order. This is NOT a proof of interval effects, allocator canonical validity, non-overlap or page conservation. Alloc/free trace specs are authored semantic models directly mirroring the recursive branching and checked against actual method bodies. The remaining interval interpretation is a substantive missing theorem, not an assumed import. No new target or replacement executable algorithm.

The operational layout is the equivalent local recurrence n[0]=len; n[o+1]=floor(n[o]/2), retaining all u32 lengths/orders, multiword bitmaps and partial boundaries. It drops canonical/free-ownership requirements because the partial guarantee holds more broadly; legal full-domain calls are included. It must not be advertised as proving that arbitrary free is legal. Equivalence to floor(len/2^o), and admission of all frozen valid states, must be checked separately before claiming full source-domain fidelity. All new semantic definitions, arithmetic/frame proof lemmas, snapshots and directives are costs. No common engineering is requested at this point.
